## Cross-comparison

**Evidence** · `conflicting` — sources disagree materially, or one source contradicts itself

What each source actually says, as fetched and read:

- **[1](../../../../../REFERENCES.md#ref-1)** — Sloperama's entry is only that mah-jongg was adopted by British sailors who nicknamed the game 'Bones' because the tiles were made of bone; it gives no tile count or hand size and points to gunplot.net
- **[25](../../../../../REFERENCES.md#ref-25)** — the gunplot.net guide presents the game as ROYAL AUSTRALIAN NAVY practice, not Royal Navy: it describes pussers bones as handed down by sailors moving between ships, with rules that were surprisingly standard, and the author learning it at sea in 1975. Reachable from this environment only through the Wayback Machine
- **[62](../../../../../REFERENCES.md#ref-62)** — a full rules book whose title page reads 'How to play the Royal Australian Navy version of Mah Jong, by Choco Munday'. Its contents cover Major Bones, the sailors' names for the tiles, game preparation, gameplay, strategy, scoring with fixed scores, penalties, points and doubles, and Bones etiquette. Most of the body is scanned images, so only the structure and title could be read as text

**Reading it:** Three sources now say Australian and none says Royal Navy. The rules book the tradition is built on is titled 'How to play the Royal Australian Navy version of Mah Jong', the gunplot.net guide presents Royal Australian Navy practice with the author learning it at sea in 1975, and a search result independently labels it the Australian Navy rules. Sloperama says only that British sailors adopted the game and nicknamed it Bones, which is about the name's origin, not the ruleset. The chart's 'Royal Navy' looks like a compression of the two: the nickname is British, the codified game is Australian.

All sources above were fetched and read on 2026-09-18. Nothing here is second-hand: a claim that could not be read at its source is not in this table.
